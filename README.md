# Anduin

Anduin is an enterprise management system, currently initialized as a minimal Go project.

## Requirements

- Go 1.23 or newer

## Getting started

```bash
go run .
```

Expected output:

```text
Anduin
```

## Development

```bash
make fmt
make vet
make test
make build
```

No HTTP APIs, database integrations, or third-party dependencies are included yet.
